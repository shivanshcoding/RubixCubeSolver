## 📌 About the Project  
An **AI-driven Rubik’s Cube Solver** that combines computer vision with interactive 3D visualization.  
- Detect cube states via **OpenCV + TensorFlow**  
- Solve optimally using **Kociemba’s Algorithm** (under 50 moves, ~2.5s avg)  
- Visualize step-by-step with **D3.js & Three.js**  
- Web-based solving quiz with 1000+ scrambles 🎮  

---

## ⚡ Features  
- 🔍 **AI Cube Detection**: Extract cube facelets via OpenCV & TensorFlow  
- ⚡ **Fast Solving**: Optimized solutions in ≤50 moves  
- 🎨 **Interactive 3D Visualizer**: Learn solving visually  
- 🧩 **Cube Quiz Mode**: Random scrambles + solve tracking  
- 🎓 **Educational Tool**: Used in schools & colleges with 95%+ feedback  

---

## 🛠️ Tech Stack  
- **Backend:** Python, Flask  
- **AI/ML:** OpenCV, TensorFlow, Kociemba Library  
- **Frontend:** D3.js, Three.js, JavaScript, HTML/CSS

## 🚀 Getting Started  
1. Clone the repo  
```bash
git clone https://github.com/shivanshcoding/Rubiks-Cube-Solver.git
cd Rubiks-Cube-Solver
```
2. Install dependencies
```bash
pip install -r requirements.txt
```

3. Run the app

```bash
python app.py
```

4. Open in browser → http://localhost:5000
